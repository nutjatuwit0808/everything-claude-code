# research/

โฟลเดอร์นี้เก็บ **เอกสารวิจัย** ที่ใช้ในการพัฒนา ECC — การวิเคราะห์ codebase, บันทึกการตัดสินใจ, และการศึกษาเฉพาะเรื่อง

## ภาพรวม

Research documents บันทึกข้อมูลที่ค้นพบระหว่างการพัฒนา ECC ซึ่งส่วนใหญ่เป็นข้อมูลที่ไม่อยู่ใน code โดยตรง แต่เป็น context สำคัญสำหรับการตัดสินใจออกแบบ

## ไฟล์

| ไฟล์ | คำอธิบาย |
|------|---------|
| `ecc2-codebase-analysis.md` | การวิเคราะห์โครงสร้างและสถาปัตยกรรมของ `ecc2/` (Rust control-plane) รวมถึงการประเมินความพร้อมสำหรับ production |

## วัตถุประสงค์

Research files ใช้สำหรับ:
1. **การตัดสินใจออกแบบ** — บันทึกว่าทำไมถึงเลือกแนวทางนี้ ไม่ใช่แนวทางอื่น
2. **การวิเคราะห์ก่อนการ refactor** — ทำความเข้าใจโค้ดที่มีอยู่ก่อนเปลี่ยนแปลง
3. **การศึกษา feasibility** — ประเมินว่าฟีเจอร์ใหม่เป็นไปได้หรือไม่
